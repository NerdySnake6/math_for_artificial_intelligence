## Запуск

Вычисления используют только стандартную библиотеку Python, дополнительные библиотеки не требуются.

Откройте `.ipynb` в Jupyter, VS Code или Google Colab и выполните ячейки сверху вниз.
Выводы уже сохранены: для чтения готовой работы повторный запуск не нужен.
