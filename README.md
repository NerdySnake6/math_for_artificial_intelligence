# Математика для искусственного интеллекта

Лабораторные работы:

1. [Логистическая регрессия](ЛР_1/)
2. [Математический анализ и матричное исчисление](ЛР_2/)
3. [Основы языковых моделей](ЛР_3/)
4. [Скалярное автоматическое дифференцирование](ЛР_4/)
5. [Векторный вход и бинарная классификация](ЛР_5/)

В каждой папке есть ноутбук с результатами, HTML-версия и пояснение.
В `results` сохранены графики и таблицы. Данные для запуска лежат рядом с ноутбуками.
Зависимости первых трёх работ перечислены в `requirements.txt`.
В четвёртой и пятой используется только стандартная библиотека Python.
