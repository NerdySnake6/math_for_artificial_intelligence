# Математика для искусственного интеллекта

Пять выполненных лабораторных работ. Каждая работа размещена в отдельной папке
`ЛР_1`–`ЛР_5` и содержит ноутбук с сохранёнными результатами выполнения,
HTML для просмотра без Jupyter, пояснение и папку `results`.
Необходимые исходные данные находятся в папках соответствующих работ.

## Как пользоваться

1. Откройте папку нужной лабораторной и файл `.ipynb`: GitHub показывает код и сохранённые результаты.
2. Для выполнения скачайте репозиторий и откройте ноутбук в Jupyter, VS Code или Google Colab.
3. В ЛР № 1–3 установите зависимости из `requirements.txt` соответствующей папки.
4. Сохраняйте структуру папок: данные `data` должны находиться рядом с ноутбуком.
   В ЛР № 4–5 данные включены в код, вычисления используют только стандартную библиотеку Python.

В пояснениях описано, что требовалось сделать и как объяснить полученный результат.
В репозиторий включены готовые работы; исходные методички и дублирующие ZIP-архивы не добавлены.
